# GTA VI: cine y televisión

Categoría: EDA. Autor: Roberto Cantero. Corte: 26 de noviembre de 2026.

Abro los cuadernos desde esta carpeta y ejecuto primero 01_preparacion y después 02_eda. Solo necesito Python 3.10 o posterior; Jupyter sirve para abrirlos. También puedo ejecutar `python preparar_datos.py` y `python analizar.py`. No necesito red para reproducir los recuentos.

Los JSON de entrada conservan la anotación manual, la procedencia y los límites. Los scripts verifican identificadores, fuentes y clases antes de crear CSV y resultados. La anotación es una decisión editorial revisable; no la produce un algoritmo.

No he jugado a GTA VI ni revisado todos los vídeos. No afirmo que la lista sea exhaustiva ni que las 38 fichas sean homenajes confirmados. Contar varias páginas no demuestra independencia. Las franquicias no se fuerzan a una adaptación concreta. Las exclusiones conservan las decisiones más importantes.

Los cuadernos entregados contienen las salidas reales de sus celdas, ejecutadas en orden con Python y biblioteca estándar. No se utilizó un kernel Jupyter en esta sesión.
