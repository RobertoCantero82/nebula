# Estallidos de rayos gamma

**Categoría: EDA (análisis exploratorio de datos).**

Este proyecto analiza la frecuencia anual y la distribución celeste de los estallidos de rayos gamma clasificados por el monitor GBM de Fermi. No produce predicciones propias.

## Reproducción

1. Instalar `requirements.txt`.
2. Ejecutar `analisis_estallidos_rayos_gamma.ipynb` junto al CSV.
3. Para renovar los datos, ejecutar `descargar_datos.py` y volver a ejecutar este preparador.

La respuesta XML original se conserva como evidencia de la consulta.
